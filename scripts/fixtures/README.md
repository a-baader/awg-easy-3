из commit `930dc6021024db9c8bbda7d92944aa9fef7baf3c`.
Git blob: `f79f9cc8028a3f27c2d01c9c2022d0181e36d598`.

Файл сохранён для проверки исходного поведения и миграции. Это тестовый
источник, не установщик Dual; исполняемый бит снят. Текущую установку,

в корне проекта. Проверки действующего установщика находятся в
`test-vpnctl-install-contract.py` и `test-vpnctl-reinstall.py`.
