# Совместимость с исходным AWG 0.1.6

Этот каталог содержит Compose исходной установки для миграции и rollback.
Обычная установка выполняется через `sudo ./vpnctl install`; команда
`docker compose up` в корне по умолчанию не выбирает legacy-сервис.

Профиль `legacy` включается только явно. Совместимая команда `awg-easy-3`
делегирует управление Dual в vpnctl, а старую установку обслуживает через
сохранённые migration-команды. Большой `lib/auto-update.sh` оставлен для
этого подтверждённого контракта и не является updater новой Dual-установки.
Новый updater находится в `lib/vpnctl_source_update.py` и `lib/vpnctl_boot.py`.

При откате на отдельный каталог исходного проекта используются его собственные
Compose и данные. Старые профили, ключи, `.env` и настройки не перемещаются
этой реорганизацией исходников.
