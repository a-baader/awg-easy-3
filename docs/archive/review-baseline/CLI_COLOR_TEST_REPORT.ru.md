# Проверка цветного вывода vpnctl

Дата: 29 октября 2026 года.

Цвета включаются автоматически для каждого потока, подключённого к терминалу.
Переменная NO_COLOR с любым значением и TERM=dumb отключают цвета.
Дополнительные зависимости не используются.

## Автоматические проверки

- `scripts/test-vpnctl-color.py`: 10 тестов, успешно. Включают настоящий
  псевдотерминал для `-help`, `help` и `install --help`, однократный вывод справки,
  цвета заголовков, статусов, ошибок, прогресса и вопросов; отключение цветов,
  независимые stdout/stderr, чистые JSON-файл и JSON stdout даже при TTY,
  побайтовое сохранение прямого экспорта `.conf`.
- Регрессионные проверки manager, install contract, purge, source update,
  progress и output: 103 теста, успешно. Preflight: ещё 2 теста, успешно.
- `scripts/test-vpnctl-install-output-integration.py`: успешно в изолированных
  контейнерах AWG/WG с опубликованными образами 0.2.0. Обычная установка,
  читаемый вывод, этапы в stderr, права отчёта 0600, отсутствие секретов в отчёте;
  затем `status --json`, удаление и повторная установка с `--json`.
  Проверено сохранение одного JSON-документа и разделение прогресса и результата.
- `python3 -m py_compile` для изменённых Python-модулей и нового теста,
  `sh -n vpnctl`, `git diff --check`: успешно.

Проверки не изменяют реальную установку на VPS. Проверки перезагрузки ОС и
полевых устройств остаются отложенными согласно ранее принятому решению.
