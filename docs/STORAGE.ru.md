# Хранение backup и кешей

`vpnctl storage status` показывает размер, возраст, принадлежность и защиту
внутренних архивов, release manifest, кешей Git-исходников и защищённых снимков
установленного CLI. При недостатке свободного места выдаётся предупреждение;
оно также появляется перед backup и загрузкой исходников обновления.

Автоматического удаления нет. Обычный uninstall сохраняет внутренние backup,
purge удаляет их; исходники при этих командах сохраняются.

```sh
sudo vpnctl storage status
sudo vpnctl storage cleanup --dry-run
sudo vpnctl storage cleanup --keep-backups 5 --keep-sources 2 --older-than-days 30
# Для автоматизации явно подтвердите удаление:
sudo vpnctl storage cleanup --keep-backups 5 --keep-sources 2 --older-than-days 30 --yes
```

Очистка сохраняет N новых ресурсов каждого типа и удаляет только более старые,
прошедшие проверку принадлежности и возраста. Рабочий checkout, активный снимок
CLI, текущие исходники и snapshot незавершённой транзакции защищены.
Повреждённые, изменённые, неизвестные файлы и symlink не присваиваются приложению
по одному имени. Для их удаления нужна отдельная проверка администратора.
Нулевые значения retention допускаются только как явные параметры очистки;
даже тогда активные исходники не удаляются.
