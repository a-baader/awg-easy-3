# Обнаружение Home-устройств внутри своего VPN

В dual-версии mDNS и SSDP остаются доступны между разрешёнными Home-клиентами
одного VPN. Ретранслятор каждого контейнера слушает только IPv4-адрес своего
VPN-интерфейса. Например, при стандартных подсетях:

| Сервис | AWG | WG |
| --- | --- | --- |
| Панель, TCP | 10.8.0.1:51821 | 10.9.0.1:51825 |
| SSDP, UDP | 10.8.0.1:1900 | 10.9.0.1:1900 |
| mDNS, UDP | 10.8.0.1:5353 | 10.9.0.1:5353 |

UDP-порты обнаружения на внутренних адресах нужны для работы этой функции.
Слушатели 0.0.0.0:1900 и 0.0.0.0:5353 больше не создаются в dual-режиме.
Публичными остаются выбранные UDP-порты туннелей AWG и WG. Существовавшие
службы хоста, например SSH и chronyd, приложение не удаляет.

Multicast на 224.0.0.251:5353 и 239.255.255.250:1900 перенаправляется nftables
на собственный VPN-адрес только при поступлении со своего VPN-интерфейса
от Home-клиента. Разрешения клиентов проверяются также в ретрансляторе.
Guest, другая VPN-подсеть и физические интерфейсы VPS не участвуют.
Правила находятся только в собственной таблице приложения и обновляются
вместе с остальной политикой при изменении разрешений клиентов.

Изменение требует новых образов и перезапуска контейнеров через штатное
обновление. Изменение исходников на хосте само по себе не меняет уже
запущенный образ. Стабильный релиз 0.2.0 остаётся без изменений.
