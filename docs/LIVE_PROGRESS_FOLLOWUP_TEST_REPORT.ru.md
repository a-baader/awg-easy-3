# Повторная проверка перерисовки progress bar

Дата: 29 октября 2026 года.

Воспроизведены два пути с выводом новой строки на каждый heartbeat:
TTY с TERM=dumb и поток без TTY. В обычном xterm TTY перерисовка уже работала.
Конкретный режим запуска пользователя дополнительно запрошен.

Исправление:

- TERM=dumb больше не отключает возврат каретки в настоящем TTY; цвета
  по-прежнему выключены. Все TTY используют одну строку и кадры раз в 200 мс.
- Без TTY сохраняются смены этапов и итог. Периодические кадры не выводятся,
  поэтому терминальный захват/журнал не заполняется повторами одного этапа.
- JSON stdout, экспорт профилей, вопросы и тихий Ctrl+C сохраняют свой формат.

Проверки:

- test-vpnctl-live-progress.py: 9 тестов успешно.
- Остальные регрессионные Python-тесты: 127 успешно; всего 136.
- Четыре запуска с настоящим stderr PTY: обычный процесс и sudo, каждый
  с TERM=xterm и TERM=dumb. Проверены множественные возвраты каретки и
  отсутствие newline на каждом кадре; два newline приходятся на остановку
  индикатора и завершающий итог. JSON stdout не повреждён, ANSI при NO_COLOR нет.
- py_compile, git diff --check и локальные ссылки документации: успешно.

Скрипты диагностики и исходные потоки PTY сохранены локально:
/app/srv_awg/dual-work/evidence/live-progress-followup/.
Выпущенный 0.2.2 и его assets не изменялись.
