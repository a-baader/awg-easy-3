# Проверка обновления из стабильного релиза

> Протокол разработки перед публикацией 0.2.0. Текущий сводный статус: [TEST_REPORT.md](TEST_REPORT.md).

Дата: 2026-10-28.

`vpnctl update` без дополнительных опций проверяет последний stable-релиз,
получает исходники точного commit и готовые образы, сохраняет клиентов и
обновляет установленный CLI. Предыдущие исходники сохраняются.

## Автоматические проверки

- Source update: 16 тестов успешно.
- Host manager: 23 теста успешно.
- Контракт установки: 28 тестов успешно.
- Purge: 19 тестов успешно.
- Node: 256 тестов успешно.
- Синтаксис Python/Shell и `git diff --check`: успешно.

Проверены отсутствие stable-релиза, повторный вызов, отсутствие обязательных
опций и подтверждения без терминала, запрет понижения версии, dry-run без
загрузки или изменения данных, сетевой сбой, сверка и защита кеша исходников,
передача точного манифеста новому manager, восстановление Python modules,
восстановление подготовительного журнала и сохранение активных исходников purge.

## Настоящие контейнеры

`scripts/test-vpnctl-source-update-integration.py` успешно выполнен от root
в одноразовом Docker network namespace с временными системными файлами.
Локальный Git-репозиторий с тегом stable и готовые тестовые образы имитируют
следующий релиз без публикации на GitHub и без изменения VPS.

Проверено:

- Исходники клонируются из тега, commit и версия совпадают с манифестом.
- Обновление выполняет manager из полученных исходников в том же процессе;
  PID владельца транзакции и удерживаемые блокировки сохраняются.
- Отказ после регистрации нового CLI возвращает прежний указатель исходников,
  образы и состояния обоих VPN; незавершённого журнала не остаётся.
- Успешное обновление переключает установленный CLI на новые исходники,
  сохраняет прежний каталог, записывает source_commit и обновляет готовые образы.
- Клиенты и ключи сохранены; HTTP к обеим панелям проходит через настоящие
  Home VPN peer после обновления.
- Повторный update не меняет установку.

Сборка на стороне update не используется. Реальный systemd/OpenRC и reboot
не проверялись: системные пути перенаправлены во временный каталог.
Проверка публичного API репозитория на дату отчёта подтвердила отсутствие
опубликованного stable-релиза; RC не выбираются. Реальный stable-update
из публичного GitHub станет возможен после публикации первого stable.

Оба новых теста включены в GitHub Actions.
