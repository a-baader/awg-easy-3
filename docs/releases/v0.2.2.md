# wg-dual-easy 0.2.2

Стабильное обновление vpnctl и образов AWG/WG.

## Изменения

- Ctrl+C в меню и вложенных вопросах завершает vpnctl без traceback и
  дополнительных сообщений, с кодом 130.
- Progress bar в терминале обновляется в одной строке примерно раз в 200 мс.
- Во время ввода ответа анимация приостанавливается. Предупреждения и итоговый
  отчёт выводятся с новой строки. Длинные сообщения учитывают ширину окна.
- NO_COLOR отключает цвета, сохраняя анимацию. При перенаправлении и TERM=dumb
  сохраняется построчный журнал этапов с периодическими сообщениями раз в 10 с.
- JSON stdout и экспорт conf/QR/vpn:// сохраняют свой формат.
- mDNS/SSDP Home остаются доступны только внутри своего VPN.

## Установка

```sh
git clone https://github.com/a-baader/wg-dual-easy.git
cd wg-dual-easy
sudo ./vpnctl install
```

При необходимости укажите `--host YOUR_PUBLIC_IP`. Готовые образы загружаются
из GHCR. Первый вход в панель — через свой Home VPN; адреса, порты, пароль
и профиль показываются в терминале. См. [инструкцию](../../README.ru.md#установка-и-первый-вход).

## Обновление с 0.2.0 или 0.2.1

```sh
sudo vpnctl update
```

Команда обновляет исходники и готовые образы, сохраняя клиентов, ключи,
пароли, порты и настройки. Возможен краткий разрыв VPN. Reinstall не требуется.
Предыдущие исходники и внутренний snapshot сохраняются.
Для RC1/RC2 используйте [инструкцию перехода](v0.2.0.md#обновление-с-rc1rc2).

## Проверки

Публикация требует полного CI точного commit, включая контейнеры, сеть,
сценарии host manager и headless Chromium через оба Home VPN.
См. [протокол](../TEST_REPORT.md), [Ctrl+C](../QUIET_INTERRUPT_TEST_REPORT.ru.md)
и [интерактивную строку](../LIVE_PROGRESS_TEST_REPORT.ru.md).

Reboot ОС, reboot во время update/restore и полевые устройства остаются
отложенными по решению пользователя.
