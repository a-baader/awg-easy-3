# wg-dual-easy 0.2.4

Исправления безопасности и надёжности после полного ревью проекта.

## Изменения

- Панель доступна только Home-клиентам своей VPN-подсети. Закрыт обход через
  посторонний DNAT; multicast discovery передаётся только своему Home.
- Login ограничен по фактическому VPN-адресу и общему бюджету экземпляра.
  Две проверки bcrypt выполняются в worker threads, без очереди login и
  блокирования управления. Перегрузка возвращает 429/Retry-After; смена
  пароля во время проверки не позволяет получить сессию по старым данным.
- Logout отзывает конкретную сессию на сервере; список отзывов ограничен.
  Новые пароли ограничены 72 байтами UTF-8, старые пароли сохраняют совместимость.
- Node.js 22.23.4, Go 1.27.3, Alpine 3.23.7 и проверенные Go security-lock файлы.
  В production нет npm/Corepack/pnpm/Yarn, git и тестовых файлов.
- Watchdog завершает сервис при отказе VPN engine для перезапуска Docker.
  Настроены ограничения capabilities, памяти, CPU и числа процессов.
- Установленный vpnctl использует независимый защищённый снимок исходников;
  небезопасные права/владелец проверяются до запуска Python-кода.
- Архивы backup проверяются потоково с ранними ограничениями размера/metadata.
  Restore по умолчанию не исполняет образ из произвольного backup; отдельный
  `--trust-backup-images` явно разрешает доверие указанному архивному образу.
- Очистка учитываемых временных данных restore/recover не оставляет старые
  рабочие ключи и пароли. Неизвестные и чужие ресурсы не удаляются.
- `vpnctl storage status|cleanup` показывает использование места и предлагает
  подтверждаемую очистку backup/исходников/cache по retention, с dry-run.
- Ручное обновление и проверка после загрузки ОС используют общий процесс
  обновления исходников и готовых образов. Arch bootstrap не делает partial upgrade.
- Экспорт одного клиента больше не строит firewall и профили остальных клиентов.
  Legacy Compose включается явно; миграция исходного 0.1.6 сохранена.
- CI сканирует оба образа, сохраняет проверенные image ID и публикует их без
  пересборки. Master продвигается только после готовности stable-релиза.
  Исторические отчёты перенесены в docs/archive; текущая документация обновлена.

## Установка

```bash
git clone https://github.com/a-baader/wg-dual-easy.git
cd wg-dual-easy
sudo ./vpnctl install
```

При необходимости укажите `--host YOUR_PUBLIC_IP`. Готовые образы загружаются
из GHCR. Панели открываются через соответствующий Home VPN; пароли, порты и
пути к первым профилям установщик показывает в терминале.

## Обновление

```bash
sudo vpnctl update
```

Клиенты, ключи, пароли, порты и настройки сохраняются. Возможен краткий разрыв
VPN при замене контейнеров. Reinstall не требуется. Подробности — в
[инструкции обновления](../UPDATE_ROLLBACK.ru.md).

## Проверки и пределы

Локально прошли 279 Node tests, upstream regressions, старые AWG-клиенты при
upgrade/rollback, полный dual-network, runtime login под лимитами ресурсов и
Chromium через настоящие Home AWG/WG. Trivy: HIGH/CRITICAL = 0 для обоих образов;
три UNKNOWN относятся к неимпортируемым пакетам Go и сохранены в отчётах.
Публикация требует полного GitHub Actions точного commit, включая lifecycle,
recovery и browser. Протокол — [TEST_REPORT](../TEST_REPORT.md).

Фактические reboot/power loss и физические Windows/Android/iOS остаются отдельными
полевыми проверками. По согласованному решению web/API остаётся root с NET_ADMIN;
разделение с привилегированным helper в этот выпуск не входит.
