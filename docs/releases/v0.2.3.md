# wg-dual-easy 0.2.3

Стабильное исправление вывода progress bar vpnctl.

## Изменения

- В настоящем TTY полоса перерисовывается в одной строке, включая TERM=dumb.
- NO_COLOR и TERM=dumb отключают цвета, сохраняя возврат каретки без ANSI.
- Без TTY сохраняются только смены этапов и итог. Периодические кадры
  анимации больше не заполняют журнал повторяющимися строками.
- Вопросы приостанавливают анимацию; JSON stdout и экспорт профилей сохраняют
  свой формат. Тихий Ctrl+C сохранён.

Текущий процесс `vpnctl update` продолжает использовать код, с которым был
запущен. Если обновляется старая версия, её прежний индикатор может оставаться
до завершения команды. Следующий запуск использует установленное исправление.

## Установка

```sh
git clone https://github.com/a-baader/wg-dual-easy.git
cd wg-dual-easy
sudo ./vpnctl install
```

При необходимости укажите `--host YOUR_PUBLIC_IP`. Готовые образы загружаются
из GHCR. Первый вход — через свой Home VPN. Адреса, порты, пароль и профиль
показываются в терминале. См. [инструкцию](../../README.ru.md#установка-и-первый-вход).

## Обновление с 0.2.0–0.2.2

```sh
sudo vpnctl update
```

Обновляются исходники и готовые образы. Клиенты, ключи, пароли, порты и
настройки сохраняются. Возможен краткий разрыв VPN. Reinstall не требуется.
Предыдущие исходники и внутренний snapshot сохраняются.
Для RC1/RC2 используйте [инструкцию перехода](v0.2.0.md#обновление-с-rc1rc2).

## Проверки

Публикация требует полного CI точного commit, включая контейнеры, сеть,
host manager и headless Chromium через оба Home VPN.
См. [протокол](../TEST_REPORT.md) и [повторную проверку progress bar](../LIVE_PROGRESS_FOLLOWUP_TEST_REPORT.ru.md).

Reboot ОС, reboot во время update/restore и полевые устройства остаются
отложенными по решению пользователя.
