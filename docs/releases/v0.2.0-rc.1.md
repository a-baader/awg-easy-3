# VPN Easy Dual 0.2.0-rc.1

Предварительный выпуск форка a-baader/awg-easy-3. База: оригинальный AWG-Easy 3
0.1.6. Один репозиторий собирает два самостоятельных Linux/amd64 образа:

- ghcr.io/a-baader/awg-easy-3-awg:0.2.0-rc.1 — AmneziaWG 3.x;
- ghcr.io/a-baader/awg-easy-3-wg:0.2.0-rc.1 — официальный стандартный wireguard-go
  и wireguard-tools, принудительный userspace через TUN.

Отдельные состояния, ключи, интерфейсы и панели. Общий host CLI vpnctl
устанавливает/обновляет сервисы, управляет клиентами, создаёт проверенные
backup и восстанавливает данные после отказа. Постоянного третьего контейнера
управления нет. Панели доступны только через Home соответствующей VPN.

Сохранены AWG vpn:// и native .conf/QR; WG экспортирует .conf и стандартный QR.
Home/Guest, независимые IPv4/IPv6, GeoIP, discovery, диагностика, пять языков
и RTL используют общую кодовую базу. Исправлен обход собственной панели через
DNAT публичного порта. Обновления выполняются вручную, snapshot предшествует
изменению данных; commit и rollback имеют отдельные устойчивые фазы.

Установка из исходников этого тега описана в docs/INSTALL_DUAL.ru.md.
Для готовых образов используйте ссылки с digest из release-manifest.json;
они принимаются параметрами --awg-image и --wg-image. Манифест также подходит
для vpnctl update --manifest PATH. Не запускайте legacy install.sh для Dual.

Результаты проверок находятся в docs/TEST_REPORT.md. В выпуск включаются
локальные и GitHub Actions проверки обоих образов, сетевой матрицы,
миграции, восстановления и браузера; фактические результаты фиксируются
перед публикацией.

## Отложенные проверки

По указанию пользователя полевые проверки официальных приложений на устройствах
выполняются после релиза. Windows/Android/iOS и реальный внешний Internet пока
не подтверждены. Reboot отдельной VM и reboot посередине update/restore также
отложены; SIGKILL и restart контейнеров не заменяют эти испытания.

Поэтому выпуск помечен как prerelease и не получает latest. Полная Definition
of Done с reboot и полевыми проверками не объявляется выполненной.
