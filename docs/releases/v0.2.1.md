# wg-dual-easy 0.2.1

Стабильное обновление двухконтейнерного wg-dual-easy.

## Изменения

- Цветные help, результаты команд, вопросы, предупреждения и ошибки vpnctl.
- ASCII-индикаторы операций; 100% только после успешного выполнения.
- Прогресс uninstall/purge и итоговый отчёт удаления в терминале.
- Фактические UDP-порты VPN и TCP-порты панелей после установки.
- mDNS/SSDP Home работают только внутри своего VPN: сокеты на внутренних
  адресах, без 0.0.0.0:1900 и 0.0.0.0:5353. Guest и другой VPN изолированы.
- JSON stdout, файлы отчётов и экспорт профилей сохраняют свой формат.
- NO_COLOR отключает цвета. Установка выполняется без выбора Git-ветки.

## Установка

```sh
git clone https://github.com/a-baader/wg-dual-easy.git
cd wg-dual-easy
sudo ./vpnctl install
```

При необходимости задайте `--host YOUR_PUBLIC_IP`. Готовые образы загружаются
из GHCR, сборка на сервере не требуется. Первый вход — через Home VPN;
адреса панелей, порты, пароль и профиль показываются в терминале.
См. [полную инструкцию](../../README.ru.md#установка-и-первый-вход).

## Обновление с 0.2.0

```sh
sudo vpnctl update
```

Обновляются исходники и готовые образы. Сохраняются клиенты, ключи, пароли,
порты и настройки; возможен краткий разрыв VPN. Reinstall для обновления
не требуется. Старые исходники и внутренний snapshot сохраняются.
Для RC1/RC2 используйте [инструкцию перехода](v0.2.0.md#обновление-с-rc1rc2).

## Проверки

Публикация требует полного CI точного commit тега, включая контейнеры,
сетевых Home/Guest клиентов и headless Chromium через оба VPN.
См. [протокол](../TEST_REPORT.md) и [проверку discovery](../DISCOVERY_BINDING_TEST_REPORT.ru.md).

Reboot отдельной VM, reboot во время update/restore и полевые устройства
остаются отложенными по решению пользователя.
