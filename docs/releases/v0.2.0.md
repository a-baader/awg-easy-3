# wg-dual-easy 0.2.0

Первый стабильный выпуск wg-dual-easy: два самостоятельных сервиса AmneziaWG
и стандартного WireGuard, отдельные панели и единая команда vpnctl.

## Возможности

- Профили conf/QR для обоих протоколов; vpn:// и QR vpn:// для AWG.
- Панели только через собственный Home VPN, изоляция Guest и другого VPN.
- Установка с прогрессом, backup/restore, rollback/recover, reinstall и purge.
- `vpnctl update` без опций обновляет исходники и готовые образы stable-релиза.
- Читаемый CLI и публичные JSON-отчёты 0600; JSON stdout только с --json.
- Готовые образы `ghcr.io/a-baader/wg-dual-easy-awg:0.2.0` и
  `ghcr.io/a-baader/wg-dual-easy-wg:0.2.0`, Linux/amd64.

## Установка

Следуйте [короткой инструкции](../../README.ru.md#установка-и-первый-вход).
Сборка на сервере не требуется. Сохраняйте каталог исходников: установленный
vpnctl использует его. Команда работает из любого текущего каталога.

## Обновление с RC1/RC2

Старые RC не содержат нового автоматического обновления исходников. Получите
исходники стабильного тега в новый каталог и запустите их vpnctl:

```sh
git clone --branch v0.2.0 https://github.com/a-baader/wg-dual-easy.git wg-dual-easy-0.2.0
cd wg-dual-easy-0.2.0
sudo ./vpnctl update
```

Команда использует действующую конфигурацию `/etc/vpn-easy-dual/config.json`,
создаёт snapshot и сохраняет клиентов, ключи, пароли, порты и пути данных.
При нестандартном config укажите его до команды: `./vpnctl --config PATH update`.
Не используйте reinstall для обновления с сохранением клиентов.

После перехода достаточно `sudo vpnctl update`. Предыдущие исходники
сохраняются; установленный CLI переключается на исходники точного stable commit.
При обновлении возможен краткий разрыв VPN.

## Проверки и ограничения

См. [протокол проверок](../TEST_REPORT.md). Публикация требует успешного полного
GitHub Actions для точного commit тега, включая реальные контейнеры, сетевые
клиенты, откат/восстановление и headless браузер через оба Home VPN.

Reboot отдельной VM, reboot во время update/restore и полевые устройства
ранее отложены пользователем и остаются отложенными. Они не выдаются за
пройденные проверки стабильного выпуска.
