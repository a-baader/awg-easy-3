# Проверка интерактивной полосы прогресса

Дата: 29 октября 2026 года.

TTY: одна перерисовываемая строка stderr, обновление примерно раз в 200 мс,
полоса в начале строки, ограничение по ширине окна и очистка остатка текста.
При ширине TTY 0 применяется резервная ширина 80 символов.
При перенаправлении и TERM=dumb — прежний построчный формат с периодом 10 с.
NO_COLOR сохраняет анимацию без ANSI; используются возврат каретки и пробелы.

Вопросы приостанавливают обновление до получения ответа, в том числе после
предупреждений. Сообщения, завершение и Ctrl+C закрывают активную строку.
stdout с JSON и экспортом не используется для индикаторов.
