# Контракт установки vpnctl

Основа поведения — установщик оригинального AWG-Easy 3 0.1.6
(`930dc6021024db9c8bbda7d92944aa9fef7baf3c`).

Уточнения пользователя, обязательные для Dual:

- Команда работает независимо от текущего каталога.
- Удаление и чистая переустановка требуют явного подтверждения; в автоматизации
  подтверждением служит `--yes`.
- Удаляются рабочие клиенты, ключи, пароль, настройки и bootstrap-профили
  выбранных компонентов. Внутренние backup сохраняются для восстановления.
- После удаления последнего компонента удаляется установленная команда
  `vpnctl`. Для новой установки используется `vpnctl` из оставшихся исходников.
- Docker, чужие контейнеры, сети и файлы не удаляются. Текущие значения
  forwarding хоста не сбрасываются.
- После загрузки ОС включается проверка stable-релиза, как в оригинале.
- Reboot-тесты и проверки на физических клиентах отложены по решению
  пользователя. Проверка unit-файлов не заменяет reboot-тест.

Исходники, журналы и backup могут содержать прежнюю конфигурацию; сохранение
backup означает сохранение старых ключей и клиентов внутри этих архивов.
