# Переименование в wg-dual-easy

Репозиторий проекта: https://github.com/a-baader/wg-dual-easy.
Название панели, PWA, npm-пакета и OCI metadata — `wg-dual-easy`.
Команда управления остаётся `vpnctl`. Ссылка на профиль автора оригинала
удалена из панели; атрибуция исходного проекта сохранена в NOTICE и документации.

## Совместимость установок

Каталоги `/etc/vpn-easy-dual`, systemd/OpenRC units, Compose service names,
имена контейнеров, nftables tables и признаки владения ресурсами сохранены.
Переименование не требует удаления клиентов, ключей, паролей или настроек.
Существующие установки могут продолжать использовать прежний каталог исходников.

Релизы `v0.2.0-rc.1` и `v0.2.0-rc.2`, их теги и опубликованные образы
не изменяются. Установка rc.2 по умолчанию получает прежний опубликованный
образ, поэтому новое оформление появится при сборке исходников через `--build`
или после отдельного нового релиза. Compose rc.2 сохраняет существующие ссылки
на `ghcr.io/a-baader/awg-easy-3-awg` и `ghcr.io/a-baader/awg-easy-3-wg`.

Workflow публикации формирует новые имена из имени репозитория:
`ghcr.io/a-baader/wg-dual-easy-awg` и `ghcr.io/a-baader/wg-dual-easy-wg`.
Перед следующим релизом следует обновить VERSION, версию npm-пакета, ссылки
на образы в Compose, проверку этих ссылок в workflow и тесте метаданных, а также
подготовить release notes. Старые теги не перепубликовываются.
Проверка манифеста допускает прежний namespace только для двух опубликованных RC;
для последующих версий разрешены только новые имена образов.
